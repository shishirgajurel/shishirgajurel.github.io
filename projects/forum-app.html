Forum App (ASP.NET Core Web API + Blazor)

A Reddit-style forum with a REST API, a Blazor web client and a command-line client, built on the repository pattern.

C# ASP.NET Core Web API Blazor Swagger

Overview

A small forum built step by step in the DNP (.NET) course at VIA University College. Users can register, log in, write posts and comment on them.

How it works

  • Entities for users, posts and comments, with repository interfaces in their own project
  • Two storage implementations behind the same interfaces: in memory and JSON files
  • An ASP.NET Core Web API with controllers for users, posts, comments and login, using DTOs
  • A Blazor web app that calls the API through typed HTTP services, with a custom authentication state provider
  • Swagger for trying the API, and a console client using the same repositories

What I learned

How to split an application into layers that can be swapped independently, how to design a REST API with DTOs, and how a Blazor front end handles login state.
