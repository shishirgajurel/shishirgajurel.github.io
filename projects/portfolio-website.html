Portfolio website (this site)

This website: ASP.NET Core Razor Pages with a private admin panel, SEO, security headers and a static export to GitHub Pages.

C# ASP.NET Core Razor Pages EF Core SQLite

Overview

My personal site, built with ASP.NET Core Razor Pages on .NET 10. I edit my profile and projects in a private admin panel and publish the result as static HTML to GitHub Pages.

Features

  • Admin panel with cookie login, constant-time password check and rate limiting
  • Projects with their own SEO-friendly pages, written in a simple heading/bullet format
  • Image uploads limited to JPG, PNG and WebP up to 5 MB
  • sitemap.xml, robots.txt, canonical and Open Graph tags, JSON-LD and security headers
  • A GitHub section that shows my newest public repositories automatically
  • A PowerShell script that exports the site to static files and pushes it to GitHub Pages

What I learned

Building and securing a small content-managed site end to end, Entity Framework Core with SQLite, and different ways to host a .NET app.
