Library Management System (KitabKhana)

A distributed library system with multiple logic servers, a persistence layer and a Blazor client on MySQL.

C#/.NET Java Blazor MySQL Git

Overview

KitabKhana is a library management system built by a small student team at VIA University College. Instead of one big application, it is split into several cooperating parts.

How it works

  • Logic servers that handle the library rules
  • A persistence layer that stores data in a MySQL database
  • A Blazor client that users interact with
  • Components in both C#/.NET and Java (Maven) inside one solution

What I learned

How separate services talk to each other and stay consistent, how to work across Java and .NET, and how to collaborate in a team with Git and GitHub.
