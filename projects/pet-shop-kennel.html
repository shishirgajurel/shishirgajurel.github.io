Pet Shop & Kennel Management (JavaFX)

1st-semester team project: a desktop app for a pet shop with a kennel, covering customers, pets for sale, kennel reservations and sales.

Java JavaFX FXML OOP

Overview

Built by our group (Group 6) as the SEP1 project at VIA University College. Staff can manage customers, pets for sale, kennel stays and sales from one JavaFX interface.

Features

  • Add, edit and search customers, including search by phone number
  • Pets for sale: dogs, cats, birds, fish, rodents and other animals
  • Kennel reservations with a date picker
  • Selling a pet to a customer and keeping a sales log
  • Data saved in binary files, with the pet list exported to XML

How it's built

  • An abstract Pet class with a subclass per animal type
  • Model managers that keep the logic separate from the GUI
  • JavaFX views in FXML with one controller per screen
